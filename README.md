Customer Churn Analysis | SQL, Python & Data Analytics

 Project Overview

Customer churn analysis is the process of understanding why customers stop using a company's products or services.
The goal of this project is to analyze customer, subscription, billing, and support data to identify churn patterns, understand customer behavior, and generate actionable business insights that can help improve customer retention.
This project demonstrates practical data analytics skills, including SQL, Python, data cleaning, exploratory data analysis, KPI development, and data visualization.

 Business Objectives

Calculate the overall customer churn rate and retention rate.
Analyze churn across different subscription plans and contract types.
Explore relationships between customer tenure, monthly charges, and churn.
Investigate the relationship between support escalations and customer churn.
Identify customer segments that may require retention-focused strategies.
Translate analytical findings into actionable business recommendations.

 Tools & Technologies
 
SQL: Data extraction, database exploration, and querying.
Python: Data analysis and data processing.
Pandas: Data cleaning, transformation, and aggregation.
NumPy: Numerical operations.
Matplotlib & Seaborn: Data visualization and exploratory analysis.
SQLite: Relational database management.
Jupyter Notebook: Interactive analysis and documentation.
